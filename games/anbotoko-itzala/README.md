# ANBOTOKO ITZALA

EUSKARAZ GAMES — JOKOAN DAGO

## Helburua
ANBOTOKO ITZALAren remake profesionala. Euskara da jatorrizko hizkuntza; ES/EN geroago gehituko dira.

## Jokoaren nortasuna
Ekintza-abentura 3D/2.5D trinkoa, mugikorrean eta ordenagailuan arina. Euskal mitologia giro eta mekanika gisa erabiltzen da, ez apaingarri huts gisa.

## Mundua
1. Basoa Sakratua — tutorial organikoa, esplorazioa eta lehen borroka.
2. Itsaslabar Beltza — bertikaltasuna, haizea eta arriskuak.
3. Elurmendi Zuria — ikuspena, hotza eta mugimendu-probak.
4. Sakon-Koba — argia/itzala, puzzleak eta tentsioa.
5. Azken Ganbera — aurreko mekaniken sintesia eta amaiera.

## Izakiak eta buruzagiak
Basajaun, Sugaar, Tartalo eta Herensuge. Mari istorioaren ardatz nagusietako bat izango da.

## Kalitate-arauak
- Ez da menu nagusian argitaratuko vertical slice sendoa izan arte.
- 60 fps helburu iPhone/desktop gailu modernoetan; degradazio grafiko automatikoa behar denean.
- Kamera irakurgarria horizontal eta bertikalean.
- Touch eta teklatu/gamepad kontrolak lehen mailakoak.
- Save/checkpoint sistema.
- HUD txikia eta diegetikoa ahal denean.
- Audio, feedback, hit-stop arina eta animazio irakurgarriak.
- Ez da prototipo zaharra zuzenean berrerabiliko: ideia onenak bakarrik.

## Lehen vertical slice
Basoa Sakratua: sarrera zinematikoa, mugimendua, dash/saihestea, eraso arina, interakzioa, checkpoint-a, ingurune-puzzle bat, bi etsai mota eta Basajaunen lehen topaketa.
