# EUSKARAZ GAMES — produkzio bidea

## 1. ANBOTOKO ITZALA
Egoera: garapenean. Lehen vertical slice-a `games/anbotoko-itzala/index.html`.
Helburua: akzio-abentura trinkoa, euskara jatorrizko hizkuntza, mugikorra + ordenagailua.
Kapituluak: Basoa Sakratua, Itsaslabar Beltza, Elurmendi Zuria, Sakon-Koba, Azken Ganbera.
Hurrengo milestonea: Basajaun encounter, puzzle osoa, audio dinamikoa, checkpoint/save, gamepad, accesibilidad eta arte-geruza.

## 2. HERENTZIA
Ez berrerabili prototipo zaharra bere horretan. Oinarria: esplorazio 3D/2.5D, memoria eta ondarea, erabakiak, ezkutatzea eta borroka arina. Euskara lehenik. Anbotoko Itzalaren input/save/UI teknologia partekatuko du.

## 3. BASOA SOLID III
Basoa Solid II · Itsas Dorrea-ren ondorengoa. Ezkutaketa + codec + narrazio zinematografikoa. Lehen bi jokoen mekanikak hautsi gabe, etsai-IA, alertak, estaldura, boss-ak eta eszena zuzenduak hobetu.

## Ondorengo remasterrak
ARKA · Bilbao Izoztua; BIDEA 96; ELURPEKO HITZA; EVOLUTION. Kirol Challenge-k Herri Pilota, Zesta Punta eta Artzain Txakurrak mantentzen ditu eta gero estropadak, aizkora eta harri-jasotzea gehitu ahal izango dira.

## Kalitate atea
Joko bat ez da portal nagusira pasatuko honakoak gainditu arte: partida osoa amaieratik amaierara; input egonkorra; kamera; 60 fps helburu mugikorrean; save/resume; audio; UI euskara; portrait/landscape; Safari iOS; Chrome desktop; regresio-proba.
